## Consulta de CEP em Python

## Sobre o projeto

Este projeto consiste em uma aplicação de linha de comando desenvolvida em Python para consultar informações de endereços a partir de um CEP, utilizando a API pública BrasilAPI.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de programação e aprender a consumir APIs.

## Funcionalidades

- Solicitação de CEP ao usuário.
- Remoção do hífen informado no CEP.
- Validação do formato do CEP.
- Consulta de endereços por meio de uma API REST.
- Exibição de informações como rua, bairro, cidade e estado.
- Tratamento de CEPs não encontrados.
- Solicitação de um novo CEP após uma consulta sem sucesso.

## Tecnologias utilizadas

- Python
- Biblioteca Requests
- BrasilAPI — API de consulta de CEP
- Git e GitHub
  
## Como executar

- Instale o Python.
- Clone este repositório.
- Crie e ative um ambiente virtual.
- Instale a biblioteca Requests com python -m pip install requests.
- Execute o arquivo ConsultaDeCep.py.
